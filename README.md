# EaglePro for Android

EA performance tracking for MT5 accounts running the EagleVision PRO V2.0 EA, with news predictions and world news.

Every push to `main` builds a new APK. Open the **Actions** tab, click the latest green run, and download **EaglePro-APK** from the Artifacts section.

The app reads account data that the EagleVision PRO V2.0 EA sends to the app's Firebase database. Firebase settings live at the top of the EaglePro section in `www/index.html` (`const FB = {...}`).
